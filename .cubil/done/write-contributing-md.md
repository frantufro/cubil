# Write down how to build, lint and release cubil

CI enforces four commands and a pinned toolchain, `script/release` writes five
version files, and none of that is written down anywhere a contributor would
look. Skulk carries a `CONTRIBUTING.md` covering the same ground.

Write cubil's: the four commands, why the lint toolchain is pinned and how to
run it locally, a map of `src/` and `tests/`, and the release procedure from
`script/release` through the tag push to the four publish jobs. Link it from
the README.
